# Nori
Simple online messageboard web application. Built using Java, Spring Boot, React, PostgreSQL, and Hibernate ORM.

## Tech Stack

### Frontend

React Native/TypeScript project built using Expo.

### Backend

- Java 25, Spring Boot, and Hibernate ORM used for backend software
- Maven used as backend build system/package manager
- PostgreSQL database used for persistent storage of posts and post reactions

### Deployment

[Deployed](https://nori.henry.moe) on virtual private server running Ubuntu 24.04.3 LTS using an NGINX reverse proxy.
